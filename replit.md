# SmartPark — Smart Parking Management System

A full-stack parking management web app for admin and staff to manage parking slots, track vehicle entry/exit, calculate fees, view transaction history, and generate reports.

## Run & Operate

- `pnpm --filter @workspace/api-server run dev` — run the API server (port 5000)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string, `SESSION_SECRET` — session signing key

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- API: Express 5 + express-session + bcryptjs
- DB: PostgreSQL + Drizzle ORM
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)
- Frontend: React + Vite + Wouter + TanStack Query + shadcn/ui + Recharts

## Where things live

- `lib/db/src/schema/` — DB schema (users, parking_slots, vehicle_entries, parking_transactions)
- `lib/api-spec/openapi.yaml` — OpenAPI spec (source of truth for API contract)
- `lib/api-zod/src/generated/` — Zod schemas generated by Orval
- `lib/api-client-react/src/generated/` — React Query hooks generated by Orval
- `artifacts/api-server/src/routes/` — Express route handlers
- `artifacts/parking/src/pages/` — Frontend pages

## Architecture decisions

- Contract-first API: OpenAPI spec defines all routes; Zod schemas and React Query hooks are generated from it
- Session-based auth (express-session) with bcryptjs password hashing
- Fee formula: ₹20 first hour, +₹10 per additional hour (ceiling)
- Role-based access: admin can manage slots and view reports; staff can manage entry/exit
- Slot assignment: prefers matching vehicle type, falls back to any available slot

## Product

- **Login** — admin/admin123 or staff/staff123
- **Dashboard** — real-time stats (revenue, occupancy, vehicles today), weekly revenue area chart, daily occupancy bar chart
- **Slot Management** (admin only) — CRUD for parking slots with visual grid, filter by status
- **Vehicle Entry** — register vehicle entry, auto-assigns a slot, shows confirmation
- **Vehicle Exit** — search by vehicle number, shows duration & estimated fee, confirms exit
- **Transaction History** — searchable/filterable table of all completed parking sessions
- **Reports** (admin only) — daily/weekly/monthly reports with CSV export

## Gotchas

- `bcryptjs` is not available in the code_execution sandbox — generate hashes via bash using the api-server's node_modules
- Zod schema names in `@workspace/api-zod`: `CreateSlotBody` (not `SlotInput`), `UpdateSlotBody` (not `SlotUpdate`)
- The API server must be restarted after any route changes (it uses esbuild at startup)
